# Класна — школа в одном окне

Единая платформа для школ и колледжей Республики Беларусь. Объединяет то, что сейчас разбросано по шести государственным ресурсам, в одном интерфейсе с двумя кабинетами — **учителя** и **ученика**.

| Откуда взяли | Что стало в «Класне» |
|---|---|
| **profil.adu.by** — учебные программы | Календарно-тематическое планирование: у каждого урока своя тема по программе, номер урока, раздел и параграф |
| **e-padruchnik.adu.by** — электронные учебники | Учебник прикреплён к уроку и к предмету, открывается в один клик |
| **eior.by** — ЕИОР: тесты, тренажёры, база знаний | Материалы к каждому уроку; банк вопросов «Квиза дня» и самопроверки ДЗ |
| **e-vedy.adu.by** — электронные курсы | Курс по предмету в карточке урока и в каталоге |
| **lingvo.adu.by** — языковые ресурсы | Тренажёры по русскому, белорусскому и английскому |
| **Апп-бокс** — внешние приложения | GeoGebra, PhET, LearningApps, Wordwall — проверенный набор для урока |

## Возможности

**Учитель**
- «Сегодня»: уроки дня с темой по программе, незаполненный журнал, ближайшие контрольные, *что класс не понял* (по ответам учеников в квизах).
- Расписание на неделю: на каждом уроке тема, параграф, кабинет; контрольные выделены.
- Журнал урока одним экраном: посещаемость (Был / Н / Ув / Оп), оценки по 10-балльной шкале (ответ, самостоятельная, контрольная, ДЗ), смена темы, домашнее задание, учебник и материалы. Клавиатурный ввод оценок (Enter — к следующему).
- Посещаемость по классам: матрица ученик × день, динамика по неделям, зона риска.
- Успеваемость: распределение оценок, качество знаний, средний по неделям и предметам, ученики, требующие внимания.
- Программа (КТП): пройдено / по плану / отставание, статус каждой темы.
- Активность класса: стрики учеников и слабые темы.

**Ученик**
- Главная: стрик, уроки дня с темами, последние оценки, домашние задания, средний балл по предметам.
- Оценки «красной ручкой»: за год и по четвертям, сравнение со средним по классу.
- Расписание с темами, ДЗ и своими отметками.
- Домашние задания с самопроверкой (3 вопроса по теме урока).
- **Перевёрнутый урок** — материалы и превью к ближайшим темам: учебник, курс/тренажёр, 3 вопроса до занятия.
- **Подготовка к ЦТ/ЦЭ** — тренировочные варианты (10 вопросов) по предметам программы; для 5–9 классов это база к будущим экзаменам.
- **Квиз дня и стрик** — см. ниже.

### Стрик — за учёбу, а не за вход
- День засчитывается только за **Квиз дня** (5 вопросов, ≥ 60 % верных) или **самопроверку ДЗ** (3 вопроса, ≥ 60 %).
- Вопросы берутся **только для своего класса и только из разделов программы, которые класс уже прошёл по журналу** — семиклассник не получит вопрос 9 класса или тему, которой ещё не было.
- Повторное прохождение в тот же день второй день не даёт. Проверка ответов — на сервере, правильные ответы не уходят в браузер до отправки.
- Выходные и каникулы не обрывают серию, одна «заморозка» в неделю спасает пропущенный учебный день.
- Значки за 3/7/14/30 дней, опыт (XP), недельный рейтинг класса.

### Регистрация
- **Ученик** — по коду класса (вида `7B-K4P2`), который классный руководитель видит в своём кабинете. Сразу попадает в класс: расписание, темы, квиз дня и стрик работают с первого дня.
- **Учитель** — по коду школы (выдаёт администрация; в демо — `SCH12-2026`). При регистрации создаёт свой класс и отмечает предметы: нагрузка, расписание без накладок и темы уроков по программе (с текущей позиции учебного года) составляются автоматически.

### Огонёк стрика
Огонёк потухший, пока сегодня не пройден квиз или самопроверка, и вспыхивает в момент, когда день засчитан. Счётчик в верхней панели и карточка стрика обновляются сразу, без перезагрузки страницы.

## Запуск

Требуется Node.js ≥ 22.13 (используется встроенный `node:sqlite`, без нативных модулей).

```bash
npm install
npm run dev      # API :3001 + интерфейс http://localhost:5173
```

Самый простой способ — двойной клик по **«Запустить Класну.bat»**.

### Материалы и конструктор заданий (вкладки учителя «Материалы»)

- **Учебные пособия, Видеоуроки, Методика, Аудио для языков** — файлы из папки `materials/` в корне проекта; PDF, видео и аудио открываются прямо на сайте, ссылок на сторонние сервисы нет. Куда что класть — `materials/README.md`.
- **Конструктор заданий** — свои интерактивные задания пяти типов: тест, пары, пропуски, порядок, группы. Живой предпросмотр, Enter добавляет строку, Ctrl+S сохраняет, режим «на весь экран» для интерактивной доски.

### Где хранятся данные

Всё, что вносят пользователи (регистрации, журнал, оценки, посещаемость, квизы, стрик, отметки о ДЗ), сохраняется в файле **`data/klasna.db`** (SQLite) в корне проекта. Папка `data/` в git не попадает — у каждого разработчика своя база.

- Резервная копия — `npm run backup` (папка `data/backups`, в production — автоматически раз в сутки); журнал доступа к данным — `npm run audit -- 7`.
- При первом `npm run dev` / `npm start` база создаётся сама и заполняется демо-данными (школа, 4 класса — 5А, 7Б, 9А, 11А, 89 учеников, I–II четверть) на текущую дату.
- При следующих запусках данные **сохраняются**: сервер только досоздаёт недостающие таблицы.
- `npm run db` — создать или проверить базу без запуска сервера.
- `npm run seed` или **«Сбросить демо-данные.bat»** — стереть всё и заново заполнить демо-данными на сегодняшнюю дату (сервер перед этим остановить).
- Другой путь к базе: переменная окружения `KLASNA_DB`.

Демо-входы (пароль `demo`): **teacher** — учитель математики, классный руководитель 7Б; **student** — ученица 7Б; **student11** — ученик 11А (подготовка к ЦТ/ЦЭ открыта только 10–11 классам). Другие учителя: `novik`, `lukashevich`, `zhuk`, `melnik`, `klimovich`, `savitskaya`; ученики `s001`…`s087`.

Продакшн одним процессом: `npm run build && npm start` → http://localhost:3001 — сервер запускается из собранного JavaScript обычным `node`, без `tsx`. Развёртывание (Docker, несколько школ, обязательные настройки) — [docs/DEPLOY.md](docs/DEPLOY.md); данные, доступ, журнал и резервные копии — [docs/SECURITY.md](docs/SECURITY.md).

Для показа можно зафиксировать дату и время: `KLASNA_TODAY=2026-11-05 KLASNA_NOW=10:40 npm run dev` (тогда текущий урок подсвечивается как «Идёт сейчас»).

Тесты API: `npm test` — сквозные сценарии из `server/src/*.test.ts` на временной базе (права доступа, журнал, квиз и стрик, согласованность банка вопросов с программой, настройки безопасности); `data/klasna.db` они не трогают.

### Переменные окружения (сервер)

Для `npm run dev` ничего задавать не нужно — всё работает как раньше. Для публикации в интернете:

| Переменная | Что делает |
|---|---|
| `NODE_ENV=production` | Боевой режим: без своих `JWT_SECRET` и `KLASNA_SCHOOL_CODE` сервер **не запустится**; на пустой базе демо-аккаунты с паролем `demo` **не создаются**; включаются ежедневные резервные копии. |
| `JWT_SECRET` | Секрет подписи токенов входа, не короче 32 символов (`openssl rand -base64 48`). Обязателен в production. Значения по умолчанию в коде нет: в разработке без него случайный секрет создаётся один раз в `data/.jwt-secret`. |
| `KLASNA_SCHOOL_CODE` | Код учреждения для регистрации учителей (от 6 символов). Обязателен в production; демо-код `SCH12-2026` работает только в разработке и при `KLASNA_DEMO=1`. |
| `KLASNA_DEMO=1` | Явно разрешить заполнение пустой базы демо-данными и в production (например, для показа на сервере). |
| `TRUST_PROXY` | Если сервер стоит за Nginx/Cloudflare: `true` (доверять всем прокси), число (сколько прокси перед сервером, обычно `1`) или список адресов/подсетей через запятую (`loopback, 10.0.0.0/8`). Без этого все посетители выглядят как один IP, и ограничение попыток входа блокирует всех сразу. Не задан — выключено. |
| `CORS_ORIGIN` | Адреса сайта, с которых браузеру разрешено обращаться к API, через запятую: `https://klasna.example,https://www.klasna.example` (ваш домен). Не задан — только `localhost` и `127.0.0.1` на любом порту (разработка). |
| `PORT` | Порт сервера, по умолчанию `3001`. |
| `KLASNA_DB`, `KLASNA_MATERIALS` | Другой путь к базе и к папке материалов. |
| `KLASNA_BACKUP_HOURS`, `KLASNA_BACKUP_KEEP`, `KLASNA_BACKUP_DIR` | Резервные копии базы: интервал (в production по умолчанию 24 ч, в разработке выключено), сколько хранить (14), куда (`data/backups`). Вручную — `npm run backup`. |
| `KLASNA_AUDIT_DAYS` | Срок хранения журнала доступа к данным, дней (365). Выгрузка — `npm run audit -- 30`. |

Файлы из `materials/` отдаются только вошедшим пользователям (без входа — ошибка 401): сайт сам добавляет токен входа к адресам PDF, видео, аудио и картинок.

Пароли: новый пароль (регистрация, смена в профиле) — не короче 8 символов, хотя бы одна буква и одна цифра. Вход старыми паролями, включая демо-пароль `demo`, работает как прежде.

## Данные

Сайты `*.adu.by` доступны только из белорусского сегмента сети, поэтому программы (I–II четверти 5, 7, 9 классов) и список учебников собраны вручную в `server/src/data/` по структуре действующих программ. Формат позволяет заменить их выгрузкой с profil.adu.by без изменения кода; при сидировании автоматически проверяется, что каждый вопрос привязан к существующему разделу программы своего класса.

Архитектура — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
