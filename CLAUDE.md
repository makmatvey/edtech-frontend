## 1. Что это

**«Класна — школа в одном окне»** — единая школьная платформа для Республики Беларусь, сделанная на хакатоне
(ТЗ: `Downloads\Техническое задание Hackathon.pdf`, старт 05.11.2026). Два кабинета:

- **Учитель** — журнал урока (посещаемость, оценки 1–10, тема по программе, ДЗ), расписание, КТП, аналитика класса,
  материалы (учебники, видео, аудио, методика), конструктор интерактивных заданий с назначением классу.
- **Ученик** — главная со стриком, оценки «красной ручкой», дневник, ДЗ с самопроверкой, квиз дня и стрик,
  подготовка к ЦТ/ЦЭ (только 10–11 классы), профиль с достижениями, рамками и фонами.

Объединяет то, что в РБ разбросано по ресурсам: profil.adu.by (программы), e-padruchnik.adu.by (учебники),
eior.by, e-vedy, lingvo, «апп-бокс». Сайты `*.adu.by` с ПК пользователя не открываются — программы, вопросы
и каталог учебников собраны вручную в `server/src/data/`.

- GitHub: приватный `n8nautomation15/Klasna`. Ветки: `master` (основная), `makmatvey`, `kostik103` (ветки соавторов),
  `feature/*` (старые, уже влиты).
- Команда: владелец (n8nautomation15 / W1ckley), **makmatvey**, **kostik103** — коммитят часто, в т. ч. прямо в master.

## 2. Правила работы (обязательно)

**Общение и автономность**
- Отвечать и писать отчёты **только на русском**.
- Делать всё **самому, без подтверждений**: проверять в браузере обе роли, чинить найденное, доводить до конца.
- Субагентов не запускать, **если пользователь сам не попросил** («запусти параллельно агентов» — тогда можно).
- Не обходить отказы классификатора: разбор API eior.by, Wayback, антибот oz.by — запрещено.
- **Никаких ссылок на сторонние сайты в интерфейсе** — всё открывается внутри «Класны».
- Старые презентации **не удалять и не перезаписывать** — каждую новую делать отдельной.

**Git — после каждого изменения**
1. `git fetch` — ребята мержат часто.
2. Если `master` ушёл вперёд — `git merge --ff-only origin/master` или `git rebase origin/master`.
3. Коммит в `master` (сообщение по-русски, в конце `Co-Authored-By: Claude …`).
4. `git push origin master master:makmatvey master:kostik103` — ветки ребят держим равными master (fast-forward).
5. **После чужих merge-коммитов проверять, не потерялись ли наши правки** (уже было: makmatvey при конфликте выкинул
   значки тем в дневнике — пришлось возвращать `d279219`). Проверка: `git merge-base --is-ancestor <коммит> HEAD`
   и `git diff <наш коммит> HEAD -- <файлы>` по удалённым строкам.
- При rebase OneDrive может заблокировать `.git/rebase-merge` → `rm -rf .git/rebase-merge`.

**Проверка перед коммитом**
- `cd client && npx tsc --noEmit -p .` и `cd server && npx tsc --noEmit -p .`
- `npm test` (сейчас **41 тест**, все зелёные).
- Браузер: Playwright из `C:/Users/User/Documents/university-finder/node_modules/playwright`, скрипты — в scratchpad.
  Вход: `POST /api/auth/login {login,password,role}` → токен в `localStorage["klasna.token"]`.

## 3. Стек и запуск

- **Node.js ≥ 22.13** (встроенный `node:sqlite`, нативных модулей нет). Монорепо npm workspaces: `server`, `client`.
- **Сервер**: Express 4 + TypeScript, `node:sqlite` (WAL), JWT (12 ч), bcryptjs, zod. В разработке — `tsx watch`.
- **Клиент**: Vite + React 18 + TypeScript, react-router, lucide-react, шрифты `@fontsource` (Golos Text, Caveat), без CDN.

| Команда | Что делает |
|---|---|
| `npm install` | зависимости (`package-lock.json` в git) |
| `npm run dev` | API :3001 + интерфейс http://localhost:5173 (Vite проксирует `/api`, `/materials`) |
| «Запустить Класну.bat» | то же двойным кликом |
| `npm run seed` / «Сбросить демо-данные.bat» | стереть базу и заполнить демо на сегодняшнюю дату (сервер остановить) |
| `npm run db` | создать/досоздать базу без запуска сервера |
| `npm test` | все `server/src/*.test.ts` на временной базе |
| `npm run build` | `client/dist` + `server/dist` (tsc, `server/tsconfig.build.json`) |
| `npm start` | production: `node server/dist/index.js` (без tsx), отдаёт и API, и собранный клиент |
| `npm run backup` / `npm run audit -- 30` | снимок базы / выгрузка журнала доступа CSV за 30 дней |
| `npm run download-list -w server`, `npm run import-covers -w server -- "<папка>"` | чек-лист материалов, импорт обложек учебников |

## 5. Сервер: API

Все ответы JSON, ошибки `{ error: "текст по-русски" }`. Роль проверяется на уровне роутера + владение на каждом объекте.

  `POST /register` (ученик — по коду класса `7B-K4P2`; учитель — по коду школы, сразу создаёт класс, нагрузку, расписание, уроки с темами), `GET /me`.
- **/api/profile**: `GET /` (фото, рамка, фон, витрина, достижения, рамки, фоны, статистика), `PUT /` (валидация: только открытое), `PUT /password`.
- **/api/teacher**: `classes`, `dashboard`, `schedule`, `lessons/:id` (GET/PUT — журнал урока), `attendance`, `performance`,
  `curriculum` (КТП), `insights` (слабые темы), `library`, `materials`, `materials/:section`, `notifications`, `search`,
  `students/:id`, `export/attendance.csv`, `export/grades.csv`.
  **/api/teacher/tasks** (конструктор): список, CRUD, `:id/copy`, `:id/assign` (назначить классу), `:id/assignments`,
  `assignments/:id/results`, `DELETE assignments/:id`.
- **/api/student**: `overview`, `grades`, `schedule` (дневник), `homework`, `PUT homework/:lessonId` (отметка «сделано»),
  `POST homework/:lessonId/check` (самопроверка), `POST quiz/daily`, `POST quiz/:id/submit`, `classmates/:id` (карточка, только свой класс),

  `tasks`, `tasks/:assignmentId`, `POST tasks/:assignmentId/submit` (интерактивные задания от учителя).

## 6. Ключевая логика (и почему так)

**Тема урока по программе.** n-й урок предмета в классе получает n-ю тему КТП. Уроки сверх программы получают резервную тему
«Повторение и обобщение изученного» (`curriculum-sync.ts`: `ensureReserveTopic`, `topicAt`, `fillMissingTopics`) — NULL-тем нет.

**Журнал урока.** Посещаемость — только «н» / «ув» / «оп» (без цифр, «1н» запрещено). Оценка 1–10, одна за урок, «Н» снимает оценку.
Урок «заполнен» (`marked_at`) при любом содержательном сохранении — оценки, тема, ДЗ или посещаемость; будущие уроки не помечаются.

**Квизы** (`services/quiz.ts`), режимы `daily` (5 вопросов), `homework` (3, самопроверка ДЗ), `exam` (10: часть А + часть В с кратким ответом),
`flipped`. Вопросы — только своего класса и разделов, уже пройденных по журналу (`coverage`). Для 6/8 классов берётся банк 5/7,
для 10–11 — банк 11 (`quizBankGrade`). Правильные ответы не уходят в браузер; проверка в транзакции на сервере.
Квиз дня детерминирован (сид: ученик + дата + номер попытки) и без гонки (`startDailyQuiz` возвращает открытую попытку).
Самопроверка ДЗ сама отмечает ДЗ выполненным.

**Стрик.** День засчитывается только за квиз дня или самопроверку ДЗ с ≥ 60 % верных (`PASS_RATIO`). Выходные/каникулы не рвут серию,
одна «заморозка» в неделю. Хранятся только факты в `streak_days`; серия считается функцией `streakState`. Значки, XP, рейтинг класса.
UI: на главной ученика — компактная полоска `StreakStrip` (отсчёт до полуночи, сколько одноклассников прошли, место в классе),
большой баннер — только на `/s/streak`. **Зелёного в визуале стрика нет. Главная и страница стрика должны выглядеть по-разному.**

**Перевёрнутый урок** — не отдельная вкладка, а флаг `lessons.flipped`: учитель ставит галочку «Следующий урок — перевёрнутый» рядом с ДЗ.
Ученик видит пометку в ДЗ, дневнике и на главной; ДЗ = что изучить дома; «Проверить себя» — по новой теме. `/s/flipped` → редирект на ДЗ.

**ЦТ/ЦЭ** — только 10–11 классам (сервер `requireSenior`, меню, `SeniorOnly`). «Вариант 1–8» в формате ЦТ (часть А + часть В).
Настоящих заданий прошлых лет нет (они в платных сборниках РИКЗ/Аверсэв) — без прав не копировать, решение за пользователем.

**Домашние задания.** Список начинается **с сегодняшнего дня**; просроченных не бывает (задания со сроком раньше сегодня не показываются).
Заголовки групп: «Сегодня», «Завтра», «Пн, 9 ноя» (без «К»). Отмеченное остаётся на месте с анимацией галочки (и после самопроверки).
Строки темы в карточке ДЗ нет (решение makmatvey).

**Дневник** (`pages/student/Schedule.tsx`): тема урока — значок книги (у контрольной — красный «к/р»), по клику карточка с темой
разборчивым шрифтом; отметки крупные (34px) и по центру колонки; ДЗ рукописным шрифтом.

**Профиль** (`services/profile.ts`, `pages/Profile.tsx`, `components/ProfileBits.tsx`). Фото (data URL 192px), вкладки только «Фон» и «Рамка»;
витрина (до 3 достижений) ставится кликом в сетке достижений. 24 достижения: простых только 3 (`quiz1`, `streak3`, `perfect1`), остальные трудные
(хет-трик — три «10» за день, `perfect5`, `tens25`, `comeback`, `prof`…). 20 рамок — за отметки текущей четверти (можно потерять),
18 фонов — за «задания» (ДЗ + самопроверки + варианты ЦТ). Рамки/фоны **не продаются** — только зарабатываются.
Меню профиля (`ProfileMenu`) — у всех: профиль, тема светлая/тёмная (варианта «авто» нет), выйти. Клик в рейтинге класса → карточка одноклассника.

**Конструктор заданий** (`/t/tasks`): 5 типов — тест, пары, пропуски, порядок, группы; живой предпросмотр, Ctrl+S, режим на весь экран;
предмет — только из своих (сервер 403 на чужой); назначение классу, результаты учеников; ученик решает в ДЗ. Пары и группы проходятся с клавиатуры.
Слабая тема у учителя → `/t/tasks/new/choice?title=&subject=&grade=`.

**Меню учителя** — 5 разделов, подстраницы вкладками `.subnav`: Сегодня · Расписание (Неделя, Программа) · Класс (Успеваемость, Посещаемость,
Активность) · Материалы (Учебники, Видео, Аудио, Методика) · Конструктор заданий. Пользователь счёл 11 пунктов меню лишними.

**Материалы.** Файлы не в git; раскладка — `materials/README.md`. PDF учебников не грузим (на показе «можно подключить»), нужны обложки на полке;
без обложки — нарисованная (GLYPH в `components/materials.tsx`). Учебник может состоять из частей (`parts: {title, url|null}[]`,
ч. 1 / ч. 2 — добавил makmatvey в `services/materials.ts`). Если медиа нет совсем — `ensureDemoMaterials` кладёт демо-файлы.

## 8. Безопасность и production

Подробно — `docs/SECURITY.md`, `docs/DEPLOY.md`.
- В production обязательны `JWT_SECRET` (≥ 32 символа) и `KLASNA_SCHOOL_CODE` (не демо, ≥ 6) — иначе сервер не стартует.
  В разработке случайный секрет создаётся в `data/.jwt-secret` (смена секрета разлогинивает всех).
- `TRUST_PROXY`, `CORS_ORIGIN`, `KLASNA_DEMO=1`, `KLASNA_BACKUP_HOURS/KEEP/DIR`, `KLASNA_AUDIT_DAYS`, `KLASNA_DB`, `KLASNA_MATERIALS`, `PORT`.
- Пароль нового аккаунта: ≥ 8 символов, буква и цифра (`passwordRule`); вход старыми (`demo`) работает. bcrypt асинхронный.
- `audit_log`: изменения, просмотры учителем, отказы 401/403 — без паролей, тел запросов и токенов.
- Бэкапы: `VACUUM INTO`, в production раз в сутки, 14 копий.
- Модель развёртывания: **одна школа — один экземпляр** (своя база). Сейчас каждая школа — отдельный процесс; перед масштабом на страну
  нужен режим «один процесс — много школ» (иначе +≈5 тыс. BYN/мес. за память).
- Замер нагрузки: 1 процесс на 1 ядре — 192 запроса/с, 0 ошибок, медиана 164 мс, 120 МБ.

## 12. Подводные камни среды (Windows)

- Bash-heredoc со сложными кавычками ломается («unexpected EOF») — писать скрипты файлами (Write) и запускать.
- `Edit` требует предварительного `Read`, если файл менялся снаружи.
- Dev-сервер (`tsx watch`) перезапускается при каждой правке сервера — на пару секунд API отдаёт 500.
- Chrome держит файл текущей сессии эксклюзивно; Chrome не закрывать.
