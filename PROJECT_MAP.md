# Карта проекта (React + Vite + JS)

## Стек

- React (JavaScript, без TypeScript)
- Vite (сборщик)
- Tailwind CSS v4 (стили)
- React Router v6 (роутинг)

## Структура

- `src/main.jsx` — точка входа, оборачивает App в BrowserRouter.
- `src/App.jsx` — все маршруты (Routes).
- `src/components/Layout.jsx` — общая шапка для всех страниц (через <Outlet />).
- `src/components/ui/` — переиспользуемые UI-компоненты (кнопки, формы, карточки и т.д.). Импорт: `from '../components/ui'`.
- `src/pages/` — папка со страницами (DashboardPage, NotFoundPage).
- `src/api/client.js` — функция `apiFetch(path, options)`. Все запросы к бэку идут ТОЛЬКО через неё. Она сама подставляет baseURL и парсит ошибки.
- `src/index.css` — импорт Tailwind (`@import "tailwindcss";`).

## Правила работы с API

- Бэкенд возвращает ошибки в формате `{ code, message }` со статус-кодами HTTP.
- Бэкенд будет возвращать данные в JSON.
- `apiFetch` уже умеет доставать `message` и кидать `throw new Error(message)`.
- В компонентах мы ловим эту ошибку через `try/catch` в `useEffect`.

## Как добавить новую страницу

1. Создать файл в `src/pages/NamePage.jsx` (экспорт default).
2. Импортировать в `src/App.jsx` и добавить `<Route path="/name" element={<NamePage />} />` внутрь `<Route element={<Layout />}>`.

## 🚫 Ограничения для генерации кода

При написании любого кода для этого проекта ты ОБЯЗАН соблюдать следующие правила:

1. Никаких новых библиотек. Запрещено использовать `axios`, `react-query`, `redux`, `zustand`, `react-hook-form`, UI-библиотеки (MUI, Ant, shadcn) и любые другие сторонние пакеты, если они еще не установлены в `package.json`. Используй только встроенные возможности React и Tailwind CSS.
2. Только функциональные компоненты. Никаких классовых компонентов. Только `const Component = () => {}` и хуки.
3. Работа с API строго через `apiFetch`. Никогда не используй нативный `fetch` напрямую в компонентах. Всегда импортируй и используй `import { apiFetch } from '../api/client'`.
4. Обработка состояний. В любом компоненте, который делает запрос к API, ты ОБЯЗАН реализовать три состояния: `loading` (показ "Загрузка..."), `error` (показ текста ошибки красным цветом) и `data` (рендер успешного результата).
5. Только Tailwind для стилей. Запрещено писать кастомный CSS, использовать CSS-модули или инлайн-стили (`style={{...}}`). Все стили только через классы Tailwind.
6. Ответ форматируй четко. Если просят создать новый файл — выдай его код целиком. Если просят изменить существующий (например, добавить роут в `App.jsx`) — выдай ТОЛЬКО измененные строки или обновленный файл целиком, но без лишних объяснений.
7. Никакого TypeScript. Проект пишется на чистом JavaScript (файлы `.js` и `.jsx`).
