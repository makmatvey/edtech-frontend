1. ОБЛОЖКИ УЧЕБНИКОВ — e-padruchnik.adu.by
==============================================================================
Где: https://e-padruchnik.adu.by — каталог учебных пособий с обложками.
Брать издание на 2026/2027 учебный год, на русском языке (белорусский язык и литература — на белорусском).

БЫСТРЫЙ СПОСОБ (обложки разложатся сами):
  1. Откройте в Chrome страницу каталога с обложками (например, все учебники одного класса).
  2. Ctrl+S → тип «Веб-страница полностью» → сохраните в одну папку, например Загрузки\обложки.
  3. Повторите для каждого класса 5–11 (в ту же папку).
  4. Выполните в папке проекта:  npm run import-covers -w server -- "%USERPROFILE%\Downloads\обложки"
     (или просто напишите Claude «обложки в Загрузках\обложки» — разложит сам).

РУЧНОЙ СПОСОБ: правой кнопкой по обложке → «Сохранить картинку как…» → имя «Алгебра 7.jpg»
  прямо в папку учебника ниже, либо всё в одну папку и тот же import-covers.

PDF (по желанию): кнопка скачивания PDF у пособия → в ту же папку учебника.
Если учебник из нескольких частей — все PDF в ту же папку: «Часть 1.pdf», «Часть 2.pdf».
