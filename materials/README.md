# Папка материалов «Класны»

Всё, что лежит здесь, сайт показывает у себя: PDF, видео и аудио открываются прямо в «Класне», без переходов на другие сайты.
Папки создаются автоматически при запуске сервера (`npm run dev`). Новые файлы появляются на сайте через несколько секунд, перезапуск не нужен.

Файлы в git **не попадают** (они тяжёлые), в репозитории есть только этот README. Материалы между разработчиками передавайте архивом или через облако (Google Drive, Яндекс Диск) и распаковывайте в эту папку.

## Что скачать

Полный чек-лист по порядку — **`СПИСОК ДЛЯ СКАЧИВАНИЯ.txt`** в этой папке: 93 учебника 5–11 классов с путями, видео, методички, аудио.
Пересобрать его после правки каталога (`server/src/data/library.ts`): `npm run download-list -w server`.

## Куда что класть

| Раздел на сайте | Папка | Форматы |
|---|---|---|
| Материалы → Учебники | `Учебники/<Предмет>/<класс>/` | обложка `.jpg .png .webp` (имя с «обложка» в приоритете) и по желанию `.pdf`; несколько частей — все PDF в ту же папку |
| Видеоуроки | `ЕИОР — Видеоуроки/<Предмет>/<класс>/` | `.mp4 .webm .m4v` |
| Методика | `Методика (profil.adu.by)/<Категория>/` | `.pdf .doc .docx .ppt .pptx` |
| Аудио для языков | `Лингва — Аудио/<Язык>/<класс>/[<подборка>]/` | `.mp3 .m4a .ogg .wav` |

Категории методики: `Интерактивные задания`, `Электронные курсы`, `Особые темы`, `Советы по предметам/<Предмет>/`.

## Обложки учебников

Обложка показывается на полке вместо цветного корешка. Массово: сохраните страницы каталога e-padruchnik («Веб-страница полностью») или картинки с именами вида «Алгебра 7.jpg» в одну папку и выполните
`npm run import-covers -w server -- "<папка>"` — скрипт сам найдёт предмет и класс и положит `обложка.jpg` в папку учебника.

## Как называть

- **Название файла = название на сайте.** `Сила трения.mp4` → «Сила трения». Подчёркивания заменяются пробелами.
- Номер в начале задаёт порядок и не показывается: `01_Введение.mp4`, `02_Сила трения.mp4`.
- Предмет — точное название папки: Математика, Алгебра, Геометрия, Русский язык, Беларуская мова, Английский язык, Физика, История Беларуси, Биология, Черчение, Астрономия.
- Класс — папка `7` или `7 класс`. Без папки класса материал считается общим для всех классов.
- Любая другая вложенная папка становится подборкой: `Лингва — Аудио/Английский язык/7/Unit 3/Dialogue 1.mp3`.

## Видео

Браузер играет `.mp4` с кодеком H.264. Если ролик не воспроизводится, перекодируйте:

```
ffmpeg -i исходник.avi -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k -movflags +faststart результат.mp4
```
